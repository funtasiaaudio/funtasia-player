# FUNtasia Player

A minimal standalone audio player by FUNtasia Audio.

## Download

Download the latest Windows release from the Releases page.

## Features

- WAV / FLAC / MP3 / AIFF playback
- Play / Pause / Stop
- Repeat
- Seek
- Volume control
- Drag & Drop
- Windows file association support

No EQ. No normalization. No limiter.
Just playback.
